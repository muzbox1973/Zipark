# Zipark 사용 설명서 (버전 1.0.0)

Zipark(집파크)는 Windows 10/11용 무료 압축 프로그램입니다. 계정·광고·구독·인터넷 연결이 필요 없고, 파일은 이 PC 밖으로 전송되지 않습니다.

- 공식 사이트: https://gptparkai.com/
- 소스 코드: https://github.com/muzbox1973/Zipark
- 라이선스: MIT

## 1. 설치와 제거

### 1.1 설치 프로그램(MSI)으로 설치
1. `Zipark-1.0.0-x64.msi`를 더블클릭합니다.
2. 라이선스(MIT)와 제3자 고지를 확인하고 **Next**를 누릅니다.
3. 설치 폴더를 정합니다. 기본값은 `C:\Program Files\Zipark`입니다.
4. **Install**을 누르면 Windows가 관리자 승인을 요청합니다. 프로그램 폴더에 파일을 복사하는 데만 필요하고, Zipark 자체는 일반 사용자 권한으로 실행됩니다.
5. 설치가 끝나면 시작 메뉴에 **Zipark**가 생기고, 설치한 사용자의 탐색기 우클릭 메뉴가 자동으로 등록됩니다.

### 1.2 포터블(설치 없이)로 사용
1. `Zipark-1.0.0-x64-portable.zip`을 원하는 폴더에 풉니다.
2. `Zipark.exe`를 실행합니다.
3. 우클릭 메뉴가 필요하면 **환경설정 → Windows 탐색기 통합 → 우클릭 메뉴 등록**을 누릅니다.

> .NET 런타임이 함께 들어 있어 따로 설치할 것이 없습니다. 압축 엔진(7-Zip)도 `engine` 폴더에 포함되어 있습니다.

### 1.3 가상 드라이브용 WinFsp (선택)
ZIP/7Z 파일을 드라이브처럼 열려면 **WinFsp**가 필요합니다. WinFsp는 무료 오픈소스 파일 시스템 드라이버입니다. Zipark는 드라이버를 몰래 설치하지 않습니다.
1. **가상 드라이브 관리자** 화면에서 **WinFsp 공식 사이트 열기**를 누르거나 https://winfsp.dev/rel/ 에 접속합니다.
2. 최신 `winfsp-x.y.z.msi`를 내려받아 설치합니다.
3. Zipark로 돌아와 **새로 고침**을 누르면 "WinFsp 설치됨"으로 바뀝니다.

ISO 탑재는 Windows 기본 기능을 사용하므로 WinFsp가 필요 없습니다.

### 1.4 제거
- **설정 → 앱 → 설치된 앱 → Zipark → 제거**를 누릅니다. 우클릭 메뉴도 함께 지워집니다.
- 포터블 버전은 환경설정에서 **우클릭 메뉴 제거**를 누른 뒤 폴더를 지우면 됩니다.
- 사용자 설정은 `%APPDATA%\Zipark`, 로그와 캐시는 `%LOCALAPPDATA%\Zipark`에 남습니다. 완전히 지우려면 두 폴더도 삭제하세요.

## 2. 처음 실행하기

1. 시작 메뉴에서 **Zipark**를 실행합니다.
2. **홈** 화면 오른쪽 **상태** 카드에서 다음을 확인합니다.
   - **압축 엔진**: "7-Zip 26.05 사용 중"처럼 표시되어야 합니다.
   - **ZIP/7Z 가상 드라이브**: WinFsp 설치 여부
   - **작업 격리**: "각 작업은 별도 프로세스에서 실행됩니다"
3. 언어와 테마는 **환경설정 → 화면**에서 바꿉니다. 한국어/영어, 라이트/다크/Windows 설정 따르기 중에서 고를 수 있습니다.
4. 옵션이 많게 느껴지면 **초보자 모드**(기본값)를 그대로 쓰세요. 압축 방식·사전 크기·솔리드 같은 상세 옵션은 **전문가 모드**에서만 보입니다.

가장 빠른 사용법은 **파일을 창에 끌어다 놓기**입니다.
- 압축 파일 하나를 놓으면 → 바로 내부를 엽니다.
- 일반 파일·폴더를 놓으면 → [새 압축 만들기]에 항목이 추가됩니다.

## 4. 새 압축 만들기

1. 왼쪽 메뉴에서 **새 압축 만들기**를 엽니다(Ctrl+N).
2. **파일 추가** / **폴더 추가**를 누르거나 파일을 끌어다 놓습니다. 잘못 넣은 항목은 선택하고 **제거**를 누릅니다.
3. **저장 위치**는 첫 항목을 기준으로 자동 제안됩니다. 바꾸려면 **찾아보기…**를 누릅니다.
4. **형식**을 고릅니다. 기본값은 **ZIP**입니다.
   - **ZIP**: 어떤 PC에서도 열리는 가장 호환성 좋은 형식
   - **7Z**: 압축률이 가장 좋고, 파일 이름까지 암호화할 수 있음
   - **TAR / GZIP / BZIP2 / XZ**: 리눅스·서버용. GZIP·BZIP2·XZ는 **파일 하나만** 압축합니다. 폴더는 먼저 TAR로 묶으세요.
5. **압축률**: 저장(압축 안 함) · 가장 빠름 · 빠름 · 보통 · 높음 · 최고. 높을수록 작아지지만 느려집니다.
6. **CPU 스레드**: Auto면 모든 코어를 씁니다. 다른 작업을 하면서 압축하려면 숫자를 줄이세요.
7. 추가 옵션
   - **항목마다 따로 압축**: 폴더 10개를 넣으면 압축 파일 10개가 만들어집니다.
   - **압축 후 무결성 검사**: 만든 직후 전체를 한 번 풀어 보며 검사합니다.
   - **분할 압축**: 7장을 참고하세요.
   - **암호 설정 (AES-256)**: 8장을 참고하세요.
8. 전문가 모드에서는 **압축 방식**(LZMA2·LZMA·PPMd·BZip2·Deflate·Deflate64), **사전 크기**, **솔리드 압축**도 정할 수 있습니다.
9. **압축 시작**을 누르면 작업 큐로 이동해 진행률·속도·남은 시간이 표시됩니다.

> 원본 파일은 절대 바꾸거나 지우지 않습니다. 결과는 임시 이름으로 쓰고 성공했을 때만 최종 이름으로 바꿉니다. 같은 이름의 압축 파일이 이미 있으면 `이름 (2).zip`처럼 새 이름으로 저장합니다.

## 5. 압축 풀기

1. **압축 해제** 화면을 엽니다(Ctrl+E).
2. **압축 파일 추가**로 여러 개를 한꺼번에 넣을 수 있습니다(일괄 해제).
   - 분할 압축은 아무 볼륨(.001, .002 …)이나 넣어도 첫 볼륨으로 자동 정리됩니다. 빠진 볼륨이 있으면 목록 아래에 이름이 표시됩니다.
3. **풀 위치**를 고릅니다.
   - **압축 파일이 있는 폴더**: 각 압축 파일 옆에 풉니다.
   - **지정한 폴더**: 모든 결과를 한 폴더로 모읍니다.
   - **압축 파일 이름으로 새 폴더를 만들어 풀기**: 기본으로 켜져 있어 파일이 흩어지지 않습니다.
4. **같은 이름의 파일이 있을 때**
   - **둘 다 유지 (기본)**: 새 파일을 `이름 (2).확장자`로 저장합니다. 기존 파일은 그대로 남습니다.
   - **건너뛰기**: 이미 있는 파일은 풀지 않습니다.
   - **덮어쓰기**: 기존 파일을 바꿉니다. 꼭 필요할 때만 쓰세요.
5. 암호가 걸린 압축 파일이면 **암호** 칸에 입력합니다. 비워 두면 필요할 때 물어봅니다.
6. **압축 풀기**를 누릅니다. **완료 후 폴더 열기**를 켜 두면 끝나자마자 폴더가 열립니다.

## 6. 압축 파일 탐색기 (내부 보기·일부만 풀기)

1. **파일 탐색기**에서 **압축 파일 열기**를 누르거나(Ctrl+O) 압축 파일을 끌어다 놓습니다.
2. 폴더를 더블클릭하면 안으로 들어가고, **↑** 버튼이나 Backspace로 상위 폴더로 갑니다.
3. 오른쪽 위 검색 칸에 이름 일부를 입력하면 전체에서 찾습니다. `*.pdf`, `보고서?.docx`처럼 와일드카드도 됩니다.
4. 파일을 **더블클릭**하면 그 파일 하나만 임시 폴더에 풀어 연결 프로그램으로 엽니다. 임시 파일은 Zipark를 닫을 때 지워집니다.
5. 여러 항목을 선택하고(Ctrl/Shift+클릭) **선택 항목 풀기**를 누르면 고른 것만 풉니다. 현재 폴더 경로는 빼고 풀립니다.
6. **모두 풀기**, **검사**, **드라이브로 탑재**도 여기서 바로 할 수 있습니다.
7. 화면 아래에 형식, 파일 수, 원본→압축 크기와 비율, 압축 방식, 솔리드 블록 수, 암호화 여부가 표시됩니다. 자물쇠 아이콘이 붙은 파일은 암호화된 파일입니다.

## 7. 분할 압축 · 파일 분할/병합

### 7.1 분할 압축 만들기
1. **분할 압축** 화면에서 **조각 크기**를 고릅니다: 100MB, 700MB(CD), 1GB, 2GB, 4GB(FAT32 한도), 사용자 지정(예: `250MB`, `3.5GB`).
2. **분할 압축** 탭에서 항목을 추가하고 형식(ZIP/7Z)을 고른 뒤 **다음: 압축 설정**을 누릅니다.
3. [새 압축 만들기]가 분할 크기가 설정된 채로 열립니다. 암호와 압축률을 정하고 시작하세요.
4. 결과는 `이름.zip.001`, `이름.zip.002` … 처럼 만들어집니다. 7-Zip 표준 분할 형식입니다.

[새 압축 만들기] 화면에서 바로 **분할 압축 (볼륨 크기)**을 켜도 됩니다.

### 7.2 분할 압축 풀기
아무 볼륨이나 열거나 압축 해제 목록에 넣으면 됩니다. 나머지 볼륨은 자동으로 찾습니다. 하나라도 빠지면 어떤 파일이 없는지 알려 줍니다.

### 7.3 일반 파일 분할 / 병합 (압축 없이)
- **파일 분할** 탭: 큰 파일을 압축하지 않고 자릅니다. `파일.001, .002 …`과 함께 `파일.fxsplit.json` 매니페스트를 만듭니다. 매니페스트에는 조각마다 SHA-256이 들어 있습니다.
- **파일 병합** 탭: 첫 조각(.001)이나 매니페스트를 고르고 **병합**을 누릅니다. 매니페스트가 있으면 조각마다 검사해서 손상되거나 빠진 조각을 정확히 찾아냅니다. 원본 전체의 SHA-256도 확인합니다.

### 7.4 볼륨 점검
**볼륨 점검** 탭에서 아무 볼륨이나 고르면 세트 종류, 찾은 볼륨, 빠진 볼륨, 전체 크기를 보여 줍니다. 지원하는 종류는 .001 번호식, ZIP 스팬(.z01 … .zip), RAR(.partN.rar / .r00)입니다.

## 8. 암호 설정과 암호화

### 8.1 압축할 때 암호 걸기
1. [새 압축 만들기]에서 **암호 설정 (AES-256)**을 켭니다.
2. **암호**와 **암호 확인**을 입력합니다. 눈 모양 버튼으로 입력한 암호를 보거나 숨길 수 있습니다.
3. 강도 막대가 매우 약함 → 매우 강함으로 표시됩니다. 경고가 나오면 따라 보세요.
4. 형식별 선택 사항
   - **7Z**: **파일 이름도 암호화**(기본 켜짐)를 켜 두면 목록조차 볼 수 없습니다.
   - **ZIP**: 암호화 방식을 AES-256(권장) 또는 ZipCrypto(취약, 오래된 프로그램 호환용) 중에서 고릅니다. ZIP은 파일 이름을 암호화하지 못합니다.

### 8.2 암호 설정 화면
- 암호를 미리 만들어 보고 강도와 개선 팁을 확인하는 곳입니다.
- **이 암호로 새 압축 만들기**를 누르면 그 암호가 메모리로만 [새 압축 만들기]에 전달됩니다. 이때는 이름까지 숨길 수 있도록 형식이 7Z로 설정됩니다.

### 8.3 암호가 걸린 압축 파일 열기
- 열 때 암호 창이 뜹니다. 틀리면 "암호가 올바르지 않습니다"라고 표시되고 다시 입력할 수 있습니다.
- 암호가 틀린 상태로는 파일을 하나도 쓰지 않습니다(부분 결과 없음).

> Zipark는 암호를 **저장하지 않습니다.** 설정·로그·명령줄 어디에도 남지 않고, 압축 엔진에는 표준 입력으로만 전달됩니다. 암호를 잊으면 복구할 방법이 없습니다.

## 9. 가상 드라이브 (ISO · ZIP · 7Z)

압축을 풀지 않고 압축 파일을 `X:` 같은 드라이브처럼 엽니다.

### 9.1 탑재하기
1. **가상 드라이브 관리자**(Ctrl+M)를 엽니다.
2. 필요하면 **드라이브 문자**를 고릅니다. 자동이면 X:부터 비어 있는 문자를 씁니다.
3. **압축 파일 탑재…**를 누르고 ZIP/7Z/ISO 파일을 고릅니다. 암호가 걸려 있으면 암호를 입력합니다.
4. 목록에 드라이브 문자, 원본, 형식, 상태, 암호화 여부, 캐시 사용량이 표시됩니다. **탐색기에서 열기**로 바로 엽니다.

파일 탐색기 화면의 **드라이브로 탑재** 버튼이나 탐색기 우클릭 메뉴 **가상 드라이브 탑재**로도 할 수 있습니다.

### 9.2 동작 방식
- ZIP/7Z 드라이브는 **읽기 전용**입니다. 복사·열기는 되고, 쓰기·삭제·이름 바꾸기는 거부됩니다.
- 파일을 열 때 **그 파일만**(7Z 솔리드 압축이면 그 블록만) 풀어 메모리/디스크 캐시에 둡니다. 같은 블록의 다른 파일은 다시 풀지 않아도 됩니다.
- 캐시 크기는 **환경설정 → 가상 드라이브**에서 정합니다(메모리 기본 256MB, 디스크 기본 2048MB). 암호화된 압축 파일의 디스크 캐시는 세션마다 새로 만든 키로 암호화되어 평문이 남지 않습니다.
- 탑재 중에는 원본 압축 파일을 수정할 수 없도록 잠급니다.

### 9.3 해제하기
- 목록에서 **탑재 해제**를 누르거나, 탐색기에서 드라이브를 우클릭해 **가상 드라이브 해제 (Zipark)**를 누릅니다.
- Zipark를 닫으면 ZIP/7Z 드라이브는 자동으로 해제됩니다. ISO는 Windows 탑재처럼 계속 유지되며, 해제 버튼이나 탐색기의 **꺼내기**로 해제합니다.

## 10. ISO 탐색기

1. **ISO 열기**로 ISO 이미지를 엽니다.
2. 파일 탐색기와 같은 방식으로 내부를 둘러보고 **선택 항목 풀기 / 모두 풀기**를 할 수 있습니다.
3. **가상 DVD로 탑재**를 누르면 Windows 가상 DVD 드라이브로 연결되고, 상단에 "E: 드라이브에 탑재됨"처럼 표시됩니다.
4. **탐색기에서 열기**, **탑재 해제** 버튼을 씁니다. 여러 ISO를 동시에 탑재할 수 있으며 관리자 권한이 필요 없습니다.

## 11. 작업 큐

- 모든 압축·해제·검사·분할 작업은 작업 큐에서 차례로 실행됩니다(Ctrl+J).
- 각 작업에 진행률, 처리 속도, 남은 시간, 현재 파일이 표시됩니다.
- **취소**: 언제든 안전하게 멈춥니다. 만들던 결과물만 지우고 원본은 그대로 둡니다.
- **모두 취소**, **완료 항목 지우기**, **동시 작업 수**(1~4) 설정이 있습니다.
- 끝난 작업의 **폴더 열기**로 결과 위치를 엽니다. 실패하면 이유가 빨간 글씨로 표시됩니다.
- 각 작업은 별도 프로세스(`Zipark.Worker.exe`)에서 실행되므로, 작업에 문제가 생겨도 Zipark 창은 닫히지 않습니다.

## 12. 파일 검사 (무결성 · 체크섬)

### 12.1 압축 파일 검사
1. **파일 검사 → 압축 파일 검사** 탭에서 **압축 파일 추가**를 누릅니다.
2. **검사 시작**을 누르면 압축 파일마다 전체를 풀어 보며 CRC 오류·손상·누락 볼륨을 확인합니다. 디스크에는 쓰지 않습니다.
3. ✔ 정상(파일 수) 또는 ✖ 오류 내용이 표시됩니다. 암호가 필요하면 물어봅니다.

### 12.2 체크섬
1. **체크섬** 탭에서 파일을 추가하고 **계산**을 누르면 CRC32와 SHA-256이 표시됩니다. SHA-256을 더블클릭하면 복사됩니다.
2. **SHA-256 목록 저장**: `sha256sum` 호환 `.sha256` 파일로 저장합니다.
3. **SHA-256 목록으로 대조**: 받은 `.sha256` 파일을 고르면 파일마다 일치 / 불일치 / 파일 없음을 표시합니다.

## 15. 안전 장치

Zipark는 압축을 풀기 **전에** 압축 파일의 목록을 검사합니다.
- **경로 탐색(Zip Slip)**: `../`, 절대 경로, 드라이브 문자, `파일:스트림` 같은 이름은 풀지 않습니다.
- **예약 장치 이름**(CON, NUL, COM1 …)과 잘못된 문자가 든 이름은 차단합니다.
- **심볼릭 링크·정션**: 압축 파일 안의 링크를 따라가지 않습니다. 푸는 위치에 링크가 있으면 그쪽으로 쓰지 않습니다.
- **압축 폭탄**: 압축 비율이나 전체 크기가 비정상적이면 풀기 전에 막습니다. 정말 필요하면 환경설정에서 상한을 조정하세요.
- **디스크 공간**: 공간이 부족하면 시작하기 전에 알려 줍니다.
- 모든 해제는 숨김 임시 폴더에 먼저 푼 뒤 검사하고 옮깁니다. 실패하거나 취소하면 임시 폴더만 지웁니다.

## 18. 문제 해결

| 증상 | 해결 |
|---|---|
| "압축 엔진이 없습니다" | 설치 폴더의 `engine\7z.exe`가 없거나 손상되었습니다. 재설치하거나, 7-Zip을 설치한 뒤 환경설정 → 압축 엔진에서 경로를 지정하세요. |
| "가상 드라이브를 사용할 수 없습니다" | WinFsp를 설치하고 가상 드라이브 관리자에서 **새로 고침**을 누르세요 (1.3 참고). |
| "드라이브 문자가 이미 사용 중입니다" | 다른 문자를 고르거나 **자동**으로 두세요. |
| "압축 폭탄으로 의심되어 차단했습니다" | 신뢰할 수 있는 파일이면 환경설정 → 안전 장치에서 상한을 올린 뒤 다시 시도하세요. |
| "분할 볼륨이 누락되었습니다" | 표시된 이름의 볼륨을 같은 폴더에 넣으세요. |
| "압축 파일이 손상되었거나 데이터 오류가 있습니다" | 파일을 다시 내려받으세요. 파일 검사로 어느 파일이 손상됐는지 확인할 수 있습니다. |
| 우클릭 메뉴가 안 보임 | Windows 11은 **더 많은 옵션 표시** 안에 있습니다. 그래도 없으면 환경설정에서 **우클릭 메뉴 등록**을 다시 누르세요. |
| 그 밖의 오류 | 환경설정 → **로그 폴더 열기**(`%LOCALAPPDATA%\Zipark\logs`)의 로그를 첨부해 문의하세요. 로그에는 암호나 파일 내용이 기록되지 않습니다. |

## 19. 자주 묻는 질문

**정말 무료인가요?** 개인·기업 모두 영구 무료입니다. 광고, 구독, 유료 기능이 없습니다.

**인터넷에 연결하나요?** 아니요. 파일도 사용 정보도 외부로 보내지 않습니다. 사용자가 직접 누르는 유튜브·공식 사이트·WinFsp 링크만 브라우저로 엽니다.

**7-Zip보다 빠른가요?** 7-Zip 엔진을 그대로 쓰므로 압축률은 같고 속도도 거의 같습니다. 해제는 안전 검사 때문에 아주 조금 더 걸립니다. 측정 결과는 `docs/PERFORMANCE_REPORT.md`에 있습니다.

**압축을 풀었더니 `이름 (2)` 파일이 생겼어요.** 같은 이름의 파일이 이미 있어서 기존 파일을 보호하려고 새 이름으로 저장한 것입니다. 바꾸려면 환경설정에서 충돌 처리 방식을 고르세요.

**가상 드라이브에 파일을 저장할 수 있나요?** 아니요. 원본을 보호하기 위해 읽기 전용입니다. 수정하려면 파일을 다른 곳에 복사하세요.
