[1.0.0] — 2026-11-03 · 첫 정식 버전

추가

  • 압축·해제: ZIP, 7Z, TAR, GZIP, BZIP2, XZ 만들기. RAR/RAR5, ISO, CAB, WIM 등 열기·풀기. 엔진은 7-Zip 26.05입니다.
  • 압축률 6단계, 멀티코어(스레드 수 지정), 항목마다 따로 압축, 압축 후 무결성 검사를 지원합니다.
  • 분할 압축: 100MB / 700MB / 1GB / 2GB / 4GB / 사용자 지정 크기로 나눕니다. 첫 볼륨에서 나머지를 자동 인식하고 누락 볼륨을 탐지합니다. 지원 방식은 .001, .z01+.zip, .partN.rar, .r00입니다.
  • 일반 파일 분할·병합: 압축 없이 나누고 합칩니다. 조각별·전체 SHA-256 매니페스트로 손상과 누락을 찾아냅니다.
  • 암호화: 7Z AES-256(파일 이름 암호화 포함), ZIP AES-256을 지원합니다. ZipCrypto는 경고와 함께 제공합니다. 암호 강도 표시, 표시/숨기기, 재입력 확인, 잘못된 암호 감지가 있으며 암호는 저장하지 않습니다.
  • 압축 파일 탐색기: 풀지 않고 내부를 보고, 검색(와일드카드)하고, 선택 항목만 풀 수 있습니다. 더블클릭하면 파일 하나만 임시로 풀어 엽니다.
  • 가상 드라이브
    • ISO: Windows 가상 디스크 API로 읽기 전용 탑재·해제합니다. 관리자 권한이 필요 없고 여러 개를 동시에 다룰 수 있습니다.
    • ZIP/7Z: WinFsp 기반 읽기 전용 드라이브입니다. 파일 단위(ZIP), 솔리드 블록 단위(7Z)로 필요할 때만 풉니다. 메모리+디스크 하이브리드 캐시를 쓰고, 디스크 캐시는 AES-256-GCM으로 암호화합니다. 암호화 아카이브도 지원하며 탑재 중 원본에 쓰지 못하게 잠급니다.
    • 가상 드라이브 관리자에서 드라이브 문자, 원본, 형식, 상태, 암호화 여부, 캐시 사용량을 보고 탑재·해제할 수 있습니다.
  • 작업 큐: 진행률·속도·남은 시간을 표시하고 안전하게 취소할 수 있습니다. 동시 작업 수를 정할 수 있으며, 작업마다 별도 워커 프로세스에서 실행합니다.
  • 파일 검사: 압축 파일 무결성을 검사하고 CRC32 / SHA-256을 계산합니다. sha256sum 호환 목록을 저장하고 대조할 수 있습니다.
  • Windows 탐색기 통합: 우클릭 메뉴(ZIP/7Z 압축, 고급 압축, 여기에/새 폴더에 풀기, 검사, 가상 드라이브 탑재/해제)와 연결 프로그램 등록을 제공합니다. 여러 파일을 선택하면 하나로 묶어 압축합니다.
  • 화면: Windows 11 스타일의 화면 11개, 다크/라이트, 한국어/영어 즉시 전환, 고DPI(Per-Monitor V2), 키보드 단축키, 끌어다 놓기, 대용량 목록 가상화, 초보자/전문가 모드를 지원합니다.
  • 안전 장치: Zip Slip·경로 탐색·절대 경로·대체 데이터 스트림·예약 장치 이름·심볼릭 링크를 차단합니다. 압축 폭탄과 디스크 공간 부족은 미리 막고, 파일명이 충돌하면 기존 파일을 보호합니다. 원본은 절대 바꾸지 않습니다.
  • 배포: MSI 설치 프로그램(WiX 5)과 포터블 ZIP을 제공하며 .NET 런타임과 7-Zip 엔진이 포함되어 있습니다. 상세 사용 설명서, 버전 기록, 제3자 고지, SBOM, GitHub Actions CI(빌드·테스트·라이선스 검사)도 포함됩니다.
  • 앱 안의 정보 / 홈 화면에 개발자 정보(GPT PARK), 유튜브·공식 사이트 바로가기, 사용 설명서·버전 기록 바로가기를 넣었습니다.

변경 (출시 전 결정 사항)

  • 제품명을 초기 가칭 "FreeArc X"에서 Zipark(집파크)로 바꿨습니다. 기존 압축기 FreeArc와 혼동되지 않게 하기 위해서입니다.
  • 기본 압축 형식을 ZIP으로 정했습니다.
  • 라이선스를 MIT로 정했습니다. 동봉된 7-Zip(LGPL)과 winfsp.net(GPLv3 + FLOSS 예외)은 각자의 라이선스를 따릅니다.

수정 (출시 전 검증 중 발견)

  • 병렬 부하에서 가상 드라이브 디코더가 스레드 풀을 막아 작업 취소가 늦게 처리되던 문제를 고쳤습니다. 디코더는 이제 전용 스레드에서 실행합니다.
  • 워커와 가상 드라이브 호스트가 UTF-8 BOM으로 시작하는 입력을 거부하던 문제를 고쳤습니다.
  • 환경설정을 열었을 때 왼쪽 메뉴에 이전 항목의 강조가 남던 문제를 고쳤습니다.
  • 솔리드 7Z에서 폴더의 압축 크기가 0 B로 잘못 보이던 문제를 고쳤습니다. 이제 알 수 없음(-)으로 표시합니다.
  • 형식 이름이 SEVENZIP으로 표시되던 문제를 고쳤습니다. 이제 7Z로 표시합니다.
  • 7-Zip 목록에서 암호화된 파일 목록을 암호 없이 열 때 '취소됨'으로 분류되던 문제를 고쳤습니다. 이제 '암호 필요'로 분류합니다.

알려진 제한 사항

  • ZIP/7Z 가상 드라이브를 실제 드라이브 문자로 탑재하고 탐색기에서 읽는 과정은 아직 WinFsp가 설치된 환경에서 끝까지 검증하지 못했습니다. 파일 시스템 핵심 로직은 자동 테스트를 통과했습니다.
  • Windows 11의 새 우클릭 메뉴(최상위)에는 나타나지 않고, 더 많은 옵션 표시 안에 나타납니다.
  • MSI 설치/제거와 Windows 10 환경은 아직 검증하지 않았습니다.
  • RAR 해제는 7-Zip 엔진 기능에 의존하며, 별도 RAR 샘플로 따로 테스트하지는 않았습니다.
  • "Zipark" 제품명의 상표 검색은 아직 하지 않았습니다.
